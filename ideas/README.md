# Custom —— 产品想法总览

> 本文件夹（`ideas/`）保存所有关于 **Custom** 产品的 idea（一个 idea 一个文件）。New idea 放这里，采纳后落到产品文档。

## 当前定位（2026-09-02 确认的方向）

**一句话**：帮还没建立完整学习/工作系统、没有好习惯的高中生、大学生（及想提效的人），**建立一套属于自己的学习与工作系统，并培养良好习惯**。

- **产品主体 = 习惯与系统**（不是"学什么内容"）；内容（背单词/学技能/刷题）作为用户往系统里填入的**具体实践通道**。
- **教练（Coach）+ 工具（Tool）**：既教你怎么建系统（方法论），又帮你把重复/复杂流程自动化执行。
- **驱动 = Duolingo 式习惯/成瘾机制**：连胜 streak、AI 决定提醒时机/文案、80% 吸引力（剩 20% 靠用户意义感）。
- **首块落地场景 = 高中数学**。
- **目标用户**：以**高中生 + 大学生**为主；当前渠道有限，先以**自用 + 分享给身边人**的方式执行。
- **系统形态**：内置一套**默认的学习习惯搭建系统**；后续可加**用户定制模块**（见 `用户定制习惯系统.md`）。
- **原 v0 场景**（AI 工程师技能路径）：不优先做，保留为待办清单（见 `原V0场景-待办.md`）。
