## 0. 一句话定位

> **帮还没建立完整学习/工作系统、没有好习惯的高中生、大学生（及想提效的人），建立一套属于自己的通用学习系统，并把这套系统长期坚持下来、真正学会。**

## 2. 目标用户与真实痛点

### 目标用户
- **核心**：高中生、大学生（尤其是尚未建立学习/工作系统、缺乏好习惯、效率低的这部分）
- 次要：任何想提效、想建立习惯系统的人
- 当前执行方式：**先自用**（本人就是目标用户，dogfooding 跑通）+ 分享给身边人

### 真实痛点（为什么做）
1. **没有系统**：学什么、怎么学、学到哪一步、下一步做什么——没有一套可依赖的流程，靠"感觉"和"临时起意"。
2. **没有好习惯**：三分钟热度，靠热血撑不了几天；"打鸡血"式努力无法长期持续。
3. **假努力 / 自我感动**（最核心）：
   - 抄答案当努力、看答案说"懂了"、抄笔记当输出；
   - 复述答案 ≠ 输出（只是复读机）；抄错题本 ≠ 输出（只是书法课）；
   - **"学会了"不可观测**——无法区分"识得"（眼熟）和"学得"（真的会）。
4. **缺乏正反馈与坚持杠杆**：没有"不想断"的沉没成本，也没有"看得见的进步"来支撑长期学习。

## 3. 核心价值主张

> **把"靠意志力硬撑的学习"变成"一套自动运转的系统"。**

- **教练（Coach）+ 工具（Tool）**：既教你怎么建系统（方法论），又帮你把重复/复杂流程自动化执行。
- **可验证 > 纯打卡**：用可观测的证据判定"学会了"，而不是打勾自欺。
- **既上瘾又教得深**：习惯层（streak/提醒）负责"把人拉来每天来"；深度层负责"来了之后真的学到会"。这是相对 Duolingo 的差异化（Duolingo 只做到前一半）。

## 5. 通用底层学习系统（v0 功能设计）

> 引自 `D:\Master\高考数学` 方法论，去数学化后的通用结构。这套结构是 Custom 的核心。

### 5.1 分层架构

```
【目标层】  你去哪：倒着写结果（"我学会了…" / "我考上了…"）
【循环层】  四拍循环：问题 → 猜想 → 验证 → 输出
【验证层】  每日两勾(证据) → 讲题卡(输出) → 判定卡(验收：岔路口制，不用百分制)
【内容层】  自顶向下(问题驱动)：锚点题→拆解→补概念→求解→验证→方法卡
【习惯层】  streak / 提醒 / 80% 吸引力（Duolingo 式）——让这套系统自己转
【动机层】  方法托管动机 + 意义感（补足 80% 之外的 20%）
```

### 5.2 核心执行循环：四拍循环

> 问题 → 猜想 → 验证 → 输出

普通学生的循环 = 问题→看答案→下一题（猜/验证被跳过）；**Custom 要求每一步都是自己的**。新问题 = 问题的嵌套，循环不变、入口变小。

### 5.3 验证机制：三卡（反假努力核心，Custom 最值钱的资产）

| 卡片 | 层 | 内容 | 判定 |
|---|---|---|---|
| **周成果卡**（每日两勾） | 证据 | 每天"独立做题 + 讲题"各一勾（30 秒，做了就划，没做空着） | 这是"每日习惯"，对应 streak |
| **讲题卡**（输出，四格） | 输出 | ①这题考什么 ②第一步为什么这么做 ③卡在哪一步、为什么 ④下次看到什么信号就想到这招 | 完成标准 = 四格说出口 + 讲满 3 分钟 + 卡壳不许跳过必须自指；只分完成/未完成 |
| **判定卡**（验收，老师/AI 用） | 验收 | 核心概念 = **岔路口**（必须做选择的地方，纯计算不算）；三率：做对率 / 看懂率(复述岔路口≥一半且≥1个) / 讲对率(骨架+扛住追问≥1+卡壳自指) | **红线：不用百分制**，只记"过/不过 + 卡在哪一步" |

- **防注水**：每周随机点一天问"这天勾了'做了题'，做的哪道？卡在哪？"答不上 = 当天勾选作废。**诚实成本低，说谎成本高。**
- **校准**：一次 5 题（2 易 + 2 中 + 1 难），一个知识点只校准一次。
- **采样**：每次只抽 1 题做全三验；每周各 3~5 个数据点，看趋势不看单次。

### 5.4 内容层范式：自顶向下（问题驱动）八步

> **先给一道真实锚点题，再拆解它需要什么工具，边补工具边把题做出来。**

八步：① 起点问题(锚点题，六条标准) → ② 拆解结构 → ③ 补学未知概念(按需 2-4 个) → ④ 引导求解 → ⑤ 解决问题 → ⑥ 总结知识(知识地图) → ⑦ 同类型练习验证(1 变式 + 3-5 小题，"验证不为打分，为定位") → ⑧ 沉淀方法(方法卡=动作序列口诀)

> 数学只是内容通道；换学科时，"锚点题 → 拆解 → 补概念 → 验证 → 方法卡"的范式仍成立，只换题目来源。

### 5.5 习惯层（Duolingo 式，@ideas/Custom学习系统养成点子）

- **streak**：连续学习天数可视化，形成"不想断"的沉没成本。
- **AI 提醒**：AI 决定何时发、发什么；最佳时机 = 上次使用 24h 后；7 天不用停止通知；停止前"被动攻击式"沟通（"这些通知好像对你没用，我们决定不发了"——用户反而回来）。
- **80% 吸引力**：不必达到手游/短视频级别，剩 20% 由用户自身的意义感与动力弥补。

### 5.6 动机层（@学习动机与学习方法-成稿.md）

- 分数 = 体检报告（定位落差 → 跑四拍 → 再检测）。
- 四个执行法则：任务具体化 / 复杂拆成流程 / 从感兴趣处开始 / **降低启动成本（先学 2 分钟）** / 造专注环境。
- **方法托管动机**：设计"不靠意志力也能自动跑"的系统，从此不用每天说服自己"我要努力"。
