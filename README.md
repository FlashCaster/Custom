# Truthy

> 抓 falsy 的答案，留下 truthy 的。

**Truthy** 是教学 Agent 的评测与防幻觉层：量化 agent 回答的错误率、幻觉率与引用覆盖率，用可对照的数字证明"有护栏比没护栏可靠"。

名字取自 JavaScript 的 `truthy`——一个值"被判定为真"。Truthy 做的事一模一样：判定 agent 的回答到底是真还是假。

## 项目状态

立项调研已完成并沉淀在 [`research.md`](./research.md)：五路调研验证了"AI 教学不可验证"是真实痛点（付费用户最痛、开源无评测工具、SRS agent 化空白），并提炼了可复用的选题方法论。

下一步：写 PRD → 设计评测集 → 实现双引擎评分与护栏层 → A/B 对比报告。

## 为什么需要它

- 无护栏的 AI 辅导反而会损害学习（有实证研究支撑）
- 开源社区缺少框架无关的 agent 评测工具（LangChain 官方博客承认的缺口）
- 教学场景是评测指标最可靠的场景：可验算题有标准答案、事实题有文档可查
