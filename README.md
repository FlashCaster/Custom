# Truthy

> 抓 falsy 的答案，留下 truthy 的。

Truthy 是教学 Agent 的评测与防幻觉层：固定评测集 + 双引擎评分（确定性验算 + LLM-as-Judge）+ 四道防幻觉护栏（引用强制 / 先验算再讲解 / 拒答协议 / 版本声明），输出可量化的 A/B 对比报告。

名字取自 JavaScript 的 `truthy` —— 一个值"被判定为真"。Truthy 做的事一模一样：判定 agent 的回答到底是真还是假。

## 为什么做

- 无护栏的 AI 辅导反而会损害学习（有实证研究支撑）
- 开源社区没有框架无关的 agent 评测工具（LangChain 官方博客承认的缺口，LangSmith 是商业产品）
- 教学场景是评测指标最可靠的场景：可验算题有标准答案、事实题有文档可查

## 核心能力

- **固定评测集**：概念解释题 / 可验算题 / 事实引用题三类
- **双引擎评分**：确定性验算（零幻觉、零成本）+ LLM-as-Judge（概念题 + 引用一致性）
- **防幻觉护栏**：引用强制、先验算再讲解、拒答协议、版本声明
- **A/B 对比报告**：`--baseline`（裸 LLM 直答）vs `--guarded`（Truthy 护栏层）
