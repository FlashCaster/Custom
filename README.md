# Custom（原名 Truthy）

> 让"想学 X"变成"在学 X 的第 N 步，已完成 M 个可验证产出"。

**Custom** 是个性化学习助手：输入一句话学习目标，得到一条**有产出、进度可见、可验证**的学习路径。本地运行、数据归你、模型 key 自带。

## 它做什么

```
一句话目标/职业 → LLM 生成候选路径 → 你确认后落地（所有选择透明）
  → 任务引导：左侧当前阶段+任务置顶，右上角总进度实时推进
  → 完成判定（轻验证）：quiz 自动判分（N0–N3 难度）+ 产出物验收清单
  → 每阶段必有产出（项目/文档）→ 循环直到达标
+ 输入实际问题（如面经）→ 针对性训练
```

- **定制层**：目标 + 兴趣点 → LLM 生成候选路径（防幻觉机制 = 生成后必须经你确认）
- **执行层**：游戏化任务引导，完成即推进下一任务
- **轻验证**：quiz 自动判分 + 产出物验收清单——禁止纯打卡，"学会了"可观测
- **形态**：本地 Web（FastAPI + SQLite + 原生前端），无服务器，数据与 API key 全在本地

**v0 聚焦**：AI 工程师所需技能知识点（LLM 基础 / 提示工程 / RAG / Agent / MCP / 评测 / AI 工程化）。
